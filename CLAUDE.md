# lara_demo

**lara_demo** is a Flutter + Flame mini-game collection built around the
universe of Mexican child entertainer **Lara Campos** and her cast of
characters: Rhenné (her green frog), Reina (Rhenné's pink-frog
girlfriend), Galleta (her caramel-coloured dog), and the Corazón Amigos
heart motif that ties them together.

The app lives in `lib/main.dart` → `lib/home_screen.dart`, which presents
a sticker-styled grid of game tiles. Tapping a tile pushes a
`GameScaffold` that hosts a `LaraGame` subclass — a thin `FlameGame` base
that paints the brand gradient, tracks score, and owns the HUD +
game-over overlays. Seven mini-games are wired in (Rhenné Salta, Galleta
Corre, Atrapa Corazones, Memoria Amigos, Ritmo Lara, Galleta Atrapa,
Rhenné Corre), with `rhenne_fly/` and `galleta_maze/` scaffolded but not
yet on the home screen.

Design intent is deliberately narrow: a **kid-friendly, low-stakes
Lara-brand showcase that doubles as a Flame engine demo**. All copy is
Spanish and celebratory ("¡Bien hecho!", "Jugar otra vez"); there is no
"Game Over" framing, no scary visuals, no accounts, and no persistence
beyond in-memory state. Sprites in `assets/images/` are programmatic PIL
placeholders generated by `tools/generate_sprites.py` — meant to be
swapped for real illustrations under the same filenames without touching
code. Visual identity is bright and saturated (pink/magenta, mint,
yellow, leaf green), rounded chunky shapes, sticker-pack vibe — all
driven through `LaraColors` / `LaraGradients` / `LaraTextStyles` rather
than hardcoded color literals.

## Stack

- Flutter (stable, Dart `^3.11.3`)
- [`flame`](https://pub.dev/packages/flame) `^1.37.0`
- Python + Pillow for the stand-in sprite generator (dev-only)

Target platforms: iOS, Android, Flutter web.

## Conventions

**Game lifecycle and `onGameResize` trap.** Flame fires `onGameResize`
*before* `onLoad` resolves. Any sprite/player field declared `late final`
and touched inside `onGameResize` (directly or via helpers) will throw
`LateInitializationError`. The fix used throughout the codebase: declare
those fields nullable (`Galleta?`, `Sprite?`, ...) and add a local
null-guard at the top of every method that reads them. See
`rhenne_run_game.dart`, `galleta_run_game.dart`, and
`galleta_catch_game.dart` for the pattern.

**Game base class.** Every game extends `LaraGame` (in
`lib/shared/lara_game.dart`), which:
- Paints the brand gradient as a background.
- Manages a shared `score` int via `setScore(int)`.
- Owns two overlay keys: `hud` (top score chip) and `gameOver` (centred
  card with restart + menu buttons).
- Exposes `showGameOver(message, onRestart)` to trigger the overlay.

**Hosting.** Each game is rendered inside a `GameScaffold`
(`lib/shared/game_scaffold.dart`), pushed via `Navigator.push` from
`home_screen.dart`. The scaffold owns the `AppBar`, the restart button,
and the overlay wiring. To customise just the game-over UI for a single
game, pass a `gameOverBuilder` callback when constructing `GameScaffold` —
this is how `rhenne_run` swaps the default card for its leaderboard
(`leaderboard_overlay.dart`).

**Components.** Per-game components (player, pickups, obstacles) live in
`lib/games/<game>/components/`. They typically extend `SpriteComponent`
and mix in `HasGameReference<TheGame>` so they can call game-level
callbacks like `game.onHeartPicked(...)`.

**Theme.** Always use constants from `lib/shared/lara_theme.dart`
(`LaraColors`, `LaraGradients`, `LaraTextStyles`) rather than hardcoded
`Color(0x...)` literals. The palette: pink/magenta, mint, yellow,
rhenneGreen, galletaBrown, corazonRed, plus cream/ink for neutrals.

**Copy.** All in-game text is Spanish ("¡Bien hecho!", "Puntos",
"Corazones", "Jugar otra vez", "Menú"). Tone is celebratory and
low-stakes — no "Game Over" framing, no scary visuals.

**UI/UX feel.** The app must feel smooth and polished — this is a
showcase, not a prototype. Use animation wherever it earns its keep:
button presses, score changes, pickups, transitions between screens,
game-over reveals, idle character motion. Prefer Flutter's built-in
`AnimatedContainer` / `AnimatedScale` / `Hero` / `TweenAnimationBuilder`
on the widget side, and Flame's `EffectController` + `MoveEffect` /
`ScaleEffect` / `OpacityEffect` on the game side. Avoid abrupt state
swaps, jank, or frame-rate drops; prefer a 60fps interaction over a
"correct but stiff" one. Animations should reinforce the sticker-pack,
kid-friendly vibe — bouncy, springy, generous easing — never harsh or
clinical.

## Assets

The PNGs in `assets/images/` are programmatic stand-ins authored by
`tools/generate_sprites.py` (PIL). They are placeholders, not final art —
swap real Rhenné/Galleta/Corazón illustrations into the same filenames
to upgrade visuals without touching code.

To regenerate (only needed if you edit the script):
```
python3 tools/generate_sprites.py
```

Assets are declared in `pubspec.yaml` under `flutter.assets: - assets/images/`.

## Brand context

Lara Campos is a Mexican child entertainer (b. 2012). Her hit song
"Rhenné" features her favourite green frog; "Galleta" is named after her
caramel-coloured dog. The "Corazón Amigos" merch line ties Lara, Rhenné,
and Galleta together under a heart motif — that's the canonical cast for
this app. Reina is Rhenné's pink-frog girlfriend and appears as the goal
in Rhenné Salta.

Visual identity: bright saturated palette (pinks, magenta, mint, yellow,
leaf green), rounded chunky shapes, sticker-pack vibe, glitter hearts.

## Commands

```
flutter pub get                  # install deps
flutter analyze                  # must be clean before merging
flutter test                     # widget smoke test in test/widget_test.dart
flutter run -d chrome            # web
flutter run -d <ios-sim>         # iOS sim
flutter run -d <android-emu>     # Android emu
```

The dummy in-memory leaderboard in `rhenne_run/leaderboard.dart` seeds
five fake players and treats the current run as "Lupita". It resets on
process restart — persistence is intentionally out of scope.

## Out of scope (don't add without asking)

- Licensed Lara Campos audio.
- Real illustrated art (stand-ins are deliberate).
- Persistence beyond in-memory state (no SharedPreferences, no DB).
- Localisation framework — Spanish strings are inlined.
- Online leaderboards or accounts.
